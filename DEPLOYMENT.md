# Vercel Deployment

This project is ready for deployment on Vercel.

## Steps
1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com/) and import your repository.
3. Vercel will detect the static site and deploy it automatically.

- The main entry is portfolio.html.
- The vercel.json file ensures the root URL serves portfolio.html.

## Troubleshooting
- If you see a 404, check vercel.json and portfolio.html naming.
- For custom domains, configure in Vercel dashboard.

---

For further customization, see [Vercel documentation](https://vercel.com/docs).
