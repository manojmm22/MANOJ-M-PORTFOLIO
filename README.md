# Manoj M - Portfolio Website

A modern, responsive portfolio website for a web developer and Python programmer.

## 🌟 Features

- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Modern UI/UX**: Clean and professional interface with smooth animations
- **Dark Theme**: Eye-friendly dark theme with vibrant accent colors
- **Glassmorphism Effects**: Modern glass-like visual effects
- **Fast Performance**: Optimized animations and transitions for smooth experience
- **Contact Form**: Functional PHP contact form

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS variables, gradients, and animations
- **JavaScript**: Interactive elements and typed.js for text animations
- **PHP**: Server-side contact form handling

## 📁 Project Structure

```
├── portfolio.html    # Main HTML file
├── style.css         # Stylesheet with all styling
└── README.md         # This file
```

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/manojmm22/portfolio.git
   ```

2. **Open in browser:**
   - For basic functionality: Open `portfolio.html` directly in your browser
   - For contact form: Use a local PHP server (e.g., XAMPP, WAMP, or PHP built-in server)

3. **To run with PHP server:**
   ```bash
   php -S localhost:8000
   ```
   Then visit `http://localhost:8000`

## 🎨 Customization

### Colors
Edit CSS variables in `style.css`:
```css
:root {
  --primary-color: #6a4df5;
  --accent-color: #00d4ff;
  --dark-bg: #0a0a14;
}
```

### Content
Edit the sections in `portfolio.html`:
- Hero section (name, title, description)
- Skills section
- Projects section
- Contact information
